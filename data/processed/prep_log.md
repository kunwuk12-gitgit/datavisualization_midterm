## 3. 형태 변환 (long → wide)
- 집계 지역 ['OECD', 'EU25', 'G20'] 분리 → oecd_average.csv (기준선 용도), 국가 패널 48개국

## 4. Gapminder 결합 (국가 코드 통일)
- Gapminder 코드 소문자 → 대문자 변환, meta는 iso3166_1_alpha3 열로 매칭
- 메타데이터 미매칭 국가: 없음
- 결합 후 GDP 결측 0행, 청년실업률 결측 4행 [['CHN', 2010], ['IND', 2011], ['ISR', 2024], ['LUX', 2024]] (Gapminder에 해당 국가·연도 값 없음 → 결측 유지)

## 5. 파생 변수
- premium_gap = 55-64세 프리미엄 − 25-34세 프리미엄 (세대 격차, %p)
- premium_ratio = 25-34세 / 55-64세 프리미엄
